# Pre-Migration Checklist

## Executive & Planning (Week 1-2)

### Strategy & Sponsorship
- [ ] Executive sponsor identified
- [ ] Business case approved
- [ ] Budget allocated and approved
- [ ] Timeline defined
- [ ] Success metrics established
- [ ] Steering committee formed

### Team & Organization
- [ ] Project manager assigned
- [ ] Technical leads identified
- [ ] Vendor/partner contacts established
- [ ] Internal stakeholders identified
- [ ] External stakeholder communication plan
- [ ] Training plan developed

## Assessment & Planning (Week 2-4)

### Discovery & Inventory
- [ ] Current infrastructure documented
- [ ] Application portfolio catalogued
- [ ] Dependencies mapped
- [ ] Performance baselines captured
- [ ] License audit completed
- [ ] Data inventory completed

### Readiness Assessment
- [ ] Business readiness scored
- [ ] Technical readiness assessed
- [ ] Organizational capability evaluated
- [ ] Security & compliance reviewed
- [ ] Gaps identified
- [ ] Remediation plan created

### Planning & Design
- [ ] Target architecture designed
- [ ] Migration pathway selected
- [ ] Wave/phase plan created
- [ ] Resource requirements defined
- [ ] Risk register created
- [ ] Communication plan finalized

## Pre-Execution (Week 4-6)

### Infrastructure & Tooling
- [ ] Cloud account(s) provisioned
- [ ] Network connectivity established
- [ ] Migration tools selected and procured
- [ ] Backup solutions configured
- [ ] Monitoring tools deployed
- [ ] Management tools configured

### Security & Compliance
- [ ] IAM policies defined
- [ ] Network security rules created
- [ ] Encryption standards defined
- [ ] Compliance requirements documented
- [ ] Security groups/NACLs configured
- [ ] SSL/TLS certificates prepared

### Data & Validation
- [ ] Data migration approach designed
- [ ] Data validation tests written
- [ ] Backup procedures tested
- [ ] Rollback procedures documented
- [ ] Data retention policies defined
- [ ] Retention period verified

### Testing & Quality
- [ ] Test environment created
- [ ] Test data prepared
- [ ] Test cases documented
- [ ] Regression test plan created
- [ ] Performance test plan created
- [ ] DR test plan created

## Operationalization (Week 5-6)

### Documentation
- [ ] Architecture documentation created
- [ ] Runbooks written
- [ ] Troubleshooting guides prepared
- [ ] Change procedures documented
- [ ] Support procedures documented
- [ ] Contact directory created

### Training & Knowledge Transfer
- [ ] Training curriculum developed
- [ ] Training materials prepared
- [ ] Trainer preparation completed
- [ ] Hands-on labs set up
- [ ] Knowledge base populated
- [ ] Training sessions scheduled

### Stakeholder Preparation
- [ ] Stakeholder communications sent
- [ ] FAQ prepared
- [ ] Support desk briefed
- [ ] Service desk prepared
- [ ] User communication plan executed
- [ ] Feedback channels established

## Final Approval (Day before migration)

- [ ] All teams green-lit
- [ ] Backups verified
- [ ] DR procedures tested
- [ ] Support team on-call confirmed
- [ ] Rollback procedures ready
- [ ] Go/No-Go meeting held
- [ ] Executive approval obtained
